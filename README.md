## 🚀 Fitur Utama
- **Pelaporan Sampah:** User dapat melapor sampah harian dan mengunggah foto.
- **Konversi Poin (1 Kg = 10 Poin = Rp 1.000):** Sistem otomatis menambah poin saat admin memverifikasi sampah.
- **Sistem e-Wallet:** User dapat menarik poin ke GoPay, DANA, OVO, atau ShopeePay.
- **Admin Dashboard:** Pantau analitik sampah, proses laporan, dan verifikasi penarikan uang.
